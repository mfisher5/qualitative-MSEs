## Model run results - Split Catch Metrics

This subfolder contains results for which the catch metrics were split into large/mature and small/immature fish -- output from scripts 6 and 7.

Key files that are provided are: 

`table1_mse0-7_splitCatch_species1-2_Ricker_20260819` : qMSE results for all runs, aggregated and formatted to make table 1 (Ricker stock-recruit model)

`table2_qnm0-4_perfmet_splitTC_hcra-e_qualitative_20240923`: QNM results as qualitative categories, aggregated to make table 2

`table2_qnm0-4_perfmet_splitTC_hcra-e_pSims_20240923`: QNM results as the proportion of stable matrices with the same directional output, aggregated to make table 2

*We did not need to rerun the qMSE using the Beverton-Holt model to fulfill the purpose of this supplementary exercise.*
