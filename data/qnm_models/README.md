## Data

Dia objects and matrices (.csv files) for QNM translation of quantitative MSEs

Each QNM file is labeled according to the operating model scenario (0-4 or 0-5), and the management strategy (A-E)

**Important note:** An earlier version of this study featured an additional MSE operating model scenario that could not be translated to a qualitative model structure. This OM was removed from successive iterations of the analysis. For this reason, the QNM files **have differently numbered OMs than are listed in the paper.** These files in this repo correspond to the paper QNM such that:

QNM 0 = QNM 0 paper

QNM 2 = QNM 1 paper

QNM 3 = QNM 2 paper

QNM 4 = QNM 3 paper

QNM 5 = QNM 4 paper
